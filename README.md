# HWGame3_Ecosystem_Loezee devlog

My theme for this week's game was seagulls hunting for their food. Basically, the waves expose bubbles in the sand, which means that there's an organism there for the seagull to eat. It was kind of a struggle and lowkey confusing, but I got the waves and bubbles combo to work after a while. That was my big goal for this homework, which is kind of wrong because I should've focused more on the 3 different states of each organism. I counted the waves as an organism in my head, but honestly it only has one state (maybe), which is coming in every 5 seconds or so. I think if I had more creativity and understanding of code, I would've tried more things with the wave to hit every point in the assignment, but I didn't want to mess any code up and have to backtrack. I also didn't want to do a whole life cycle with the seagull (egg, laying eggs, etc), so I thought it would be better to have them auto-spawn outside of the screen so it looks like they're just walking in. However, this came with its own challenges since some of the videos on youtube didn't include a lot of information or it just didn't work with what I had already. For a little while, prefabs confused me too, especially since I couldn't drag the regular default target into the Possible Targets section for the script. Hopefully, no more bugs appear.
